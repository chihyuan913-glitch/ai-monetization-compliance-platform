# 《公共工程計畫書 AI 合規加速工具包》使用說明

感謝您選用本工具包！本工具專為台灣營造廠工務所主管、品管人員與工程顧問設計，能在數秒內自動診斷送審計畫書之法規有效性與章節缺漏。

---

## 快速開始（3 步驟上手）

### 步驟 1：環境準備
本工具基於輕量 Python 環境開發，無需安裝複雜資料庫。
請確認電腦已具備 Python 3.10+ 及 `python-docx` 套件：
```bash
pip install python-docx
```

### 步驟 2：執行檢查
打開終端機（CMD 或 PowerShell），切換至本工具包目錄，直接執行：
```bash
python run_audit_tool.py "您的計畫書路徑.docx"
```
*(若直接執行 `python run_audit_tool.py`，亦可按提示拖入檔案或體驗內建範例)*

### 步驟 3：檢視報告
工具將在 10 秒內於相同目錄產生 `[檔名]_合規初審報告.md`，您可以：
1. 依據報告中的「廢止法規替換建議」一鍵修正舊條文。
2. 比對「品管九大章節缺漏」補齊附件自主檢查表。
3. 參考隨附之 `工程會品質計畫書合規檢核清單範本.md` 進行最終簽認送審。

---

## 包含組件清單

1. `run_audit_tool.py`：單檔一鍵合規診斷執行腳本。
2. `工程會品質計畫書合規檢核清單範本.md`：送審前品管人員勾稽標準。
3. `README.md`：快速入門手冊。
